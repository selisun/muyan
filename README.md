# 牧颜 (muyan)

飞牛 fnOS 登录页美化 fpk 应用：不修改任何系统文件，通过反向代理为 fnOS 登录页换自定义背景、加一言、放牛牛牧场动画。

## 功能

- **自定义登录页背景**：窗口页上传图片，自动转 1920x1080 WebP，刷新即生效
- **4 种美化模板**：经典（背景+一言+链接卡片）/ 聚焦（背景+居中登录框）/ 极简（纯色深青）/ 牛牛（3 头卡通牛牧场动画，眼球跟随、眨眼、输密码害羞回避）
- **一言**：`bg/quote.txt` 每行 `句子|作者`，随机展示
- **安装时自定义端口**：向导输入反代端口（默认 11766）

## 架构

- OpenResty 单容器：443 反代 fnOS 登录页（sub_filter 注入 JS）+ unix socket 窗口页
- 窗口页走飞牛统一网关（`/app/muyan`），写操作校验 `X-Trim-Isadmin` 管理员头 + Origin 同源
- 全部文件读写路径硬编码，无路径穿越；上传限 30MB

## 构建 / 安装

```
fnpack build -d .
```

应用中心上传 `muyan.fpk` 安装（fnOS 1.1.3100+）。

## 安全说明

- 应用以普通用户运行（非 root），无系统文件修改
- 反代端口仅暴露登录页镜像与公开静态资源；管理接口仅存在于统一网关 socket
- HTTPS 使用应用自签证书（CN=muyan），首次访问需信任
